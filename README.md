# CRUD com fetch (React + Vite)

## Como rodar
```bash
npm install
npm run dev
```

## Onde está cada exercício
| Exercício | Arquivo |
|-----------|---------|
| 1 | `src/exercicios/Exercicio1.jsx` |
| 2 | `src/exercicios/Exercicio2.jsx` |
| 3 | `src/exercicios/Exercicio3.jsx` |
| 4 | `src/exercicios/Exercicio4.jsx` |
| 5 | `src/App.jsx` + `src/components/` |

Por padrão a página mostra o Exercício 5. Para ver outro, troque o
import em `src/main.jsx`.

A API é o JSONPlaceholder, que simula as operações: não salva nada de
verdade e sempre responde 200/201.
